# Ticket Support EMS

> Bước 1: Vào tính năng **EMS Support** (Hỗ trợ EMS), chọn **tạo mới hoặc click chọn Ticket Support** như hình bên dướ&#x69;**.**

<figure><img src="/files/dFnGFKcbZYyTGy8MwtPu" alt=""><figcaption></figcaption></figure>

> Bước 2: Tại màn hình tạo issue hỗ trợ, người dùng nhập thông tin cần hỗ trợ. Cuối cùng bấm **Save**(**Lưu)**.

<figure><img src="/files/7R64r9mInQg7RNZ9xP2R" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
**Ghi chú** :&#x20;

1. Tên issue cần hổ trợ xử lí
2. Loại issue cần gửi
3. Nội dung issue cần hổ trợ xử lí
4. File, hình ảnh đính kèm
5. Issue cần thông báo thêm cho người nào phụ trách nắm thông tin
   {% endhint %}

> Bước 3 : Sau khi lưu thành công, trường hợp cần bổ sung người dùng có thể nhắn vào ô **Chat** bên dưới của issue đó.

<figure><img src="/files/2FBzeb6hcT5egZ7r5CW1" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
**Ghi chú:** Người dùng có thể thả icon, đính kèm thêm file, hình ảnh trong đoạn chat
{% endhint %}
